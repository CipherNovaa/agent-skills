# Learning Style

This profile teaches the `learn` tool how you like new math / programming
concepts explained. Copy it to `~/.hermes/learning_style.md` (or set
`MYOS_LEARNING_STYLE`), seed it from how you write your own notes, and let it
grow: when you say "more worked examples" or "skip the code", the agent appends
a bullet here and the engine reads it on every run.

## How I structure a concept in my own notes

1. **Plain-language definition first** — one or two sentences, with the
   important nouns in **bold**.
2. **Step-by-step worked example** — a concrete problem solved in numbered
   steps, rewriting the expression after each step.
3. **A memory hook** — an acronym, mnemonic or rule of thumb.
4. **A gotcha** — the mistake I'd most likely make, and why it's wrong.

## Preferences

- Answer first, then the explanation.
- LaTeX for math.
- Code only for programming topics, and keep it minimal.
